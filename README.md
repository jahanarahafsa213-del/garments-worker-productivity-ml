# 🧠 Garments Worker Productivity Prediction (ML Project)

This project focuses on analyzing and predicting garments worker productivity using Machine Learning techniques, specifically the K-Nearest Neighbors (KNN) algorithm.

---

## 📊 Project Overview

The goal of this project is to:
- Analyze worker productivity data
- Build a predictive model using KNN
- Evaluate model performance
- Understand key factors affecting productivity

---

## ⚙️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

---

## 📁 Dataset

The dataset contains various features related to garments workers such as:
- Working hours
- Idle time
- Incentives
- Team performance
- Target productivity

---

## 🔍 Workflow

1. Data preprocessing  
2. Handling missing values  
3. Feature selection  
4. Model building (KNN)  
5. Model evaluation  

---

## 🤖 Model Used

- K-Nearest Neighbors (KNN)

---

## 📈 Results

- Model trained and evaluated on dataset  
- Performance analyzed using accuracy and other metrics
